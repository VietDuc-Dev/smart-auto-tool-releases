# Smart Auto Tool - Bản phát hành

Repo này chứa file cài đặt Windows và siêu dữ liệu cập nhật cho Smart Auto Tool.

## Tải xuống

- Bản mới nhất: [Trang release](https://github.com/VietDuc-Dev/smart-auto-tool-releases/releases/latest)
- Bản hiện tại: [v1.0.1](https://github.com/VietDuc-Dev/smart-auto-tool-releases/releases/tag/v1.0.1)
- File cài đặt hiện tại: `SmartAutoTool-Setup-1.0.1.exe`

Yêu cầu: Windows 10 hoặc Windows 11, phiên bản 64-bit.

## Cài đặt

1. Mở trang release ở trên.
2. Tải file `SmartAutoTool-Setup-<version>.exe` trong mục Assets.
3. Chạy file vừa tải và làm theo hướng dẫn của trình cài đặt.
4. Nếu Windows SmartScreen hiện cảnh báo, chọn **More info** rồi chọn **Run anyway**. Ứng dụng hiện chưa ký số nên có cảnh báo này.
5. Sau khi cài xong, mở **Smart Auto Tool** từ Start menu.

## Cập nhật

- Ứng dụng đã cài sẽ tự kiểm tra bản mới khi khởi động và định kỳ.
- Có thể kiểm tra thủ công tại **Settings > Cập nhật ứng dụng > Kiểm tra cập nhật**.
- `latest.yml` được dùng bởi cơ chế tự cập nhật; `latest.json` chứa thông tin phiên bản và đường dẫn tải.
